# Security policy

## Reporting a vulnerability

Report security problems privately with GitHub private vulnerability reporting. Open the Security tab of the [repository](https://github.com/zJanny/LegoCityUndercover-TheChaseBegins-PC-Port) and choose "Report a vulnerability". Do not open a public issue for a vulnerability.

Typical problems are a crash or memory error in a file decoder that a crafted game file triggers, or a tool that writes outside its output folder.

## Requests to remove game material

This is an unofficial fan project. It contains no original game assets. If you are a right holder and believe something in the repository does not belong there, report it the same way. The maintainer will review it promptly and remove what does not belong.

## Supported versions

The project has no releases. Only the current `main` branch is supported.
