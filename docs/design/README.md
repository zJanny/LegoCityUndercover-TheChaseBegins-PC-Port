# Design decisions

Specs the user approved for the plans that have no original to check against (Windows port, quality-of-life features), one file per topic. They follow the same rules as [docs/re](../re/README.md): dated entries with anchors, a `Current state` section, corrections at both ends, a split above 40 KB (CLAUDE.md "Documentation rules"). An entry records what the user approved, in their words and with the date, and what is still open; never a choice an agent made alone. Read this index, then open only the file you need.
