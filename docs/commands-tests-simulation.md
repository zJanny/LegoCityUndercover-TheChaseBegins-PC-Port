# C++ tests: simulation

Test names and what each one checks for traffic, vehicles, characters and level scripts. Some of the C++ tests, as `ctest` names. `ctest --test-dir build -N` lists all of them. Run one with `ctest --test-dir build -R <name>`.

Back to the [documentation list](../README.md#more-documentation).
