**The AI spawner class in the executable (kind 14, handler 0x1b4fb0; read in outline).**
- The message handler dispatches 7 (nothing), 8 (reset), 28 (returns a slot's halfword +0x14), 33, 252 (calls a function pointer of the message), 254 and 255. TriggerObject sends 255 for a non-zero flag and 254 for zero, then fires ObjectTriggered / ObjectUntriggered (handler 0x1cddf8).
- Message 8 reads the parameters StartActive (string at 0x1b5234) and StartSpawned (0x1b5240) through 0x2451d0, sets the state halfword +4 from StartActive, and for every slot (record +0x24 is the count, the slot array is at +0x1c in 8-byte entries) either keeps the character (StartSpawned) or holds it: 0x1b5250 sets bit 4 of the character's flags at +0xc, sends it message 53 and calls 0x2428c0. So with StartSpawned 0 the characters are held from level load until the spawner activates them.
- Message 255 with the state at 0 sets it to 1. The update callback 0x288fbc branches on the halfword +2 (1 or 2). Value 1 loops over the held slots, decrements a per-slot byte and, with the other conditions met (a function 0x265190 on a point of the slot and the camera, not read), sets the state +4 to 2 and records the slot index at +0x2b; 0x242cf0, called with the character after its flag bit 4 is cleared, clears bit 0 of the entity's halfword +0x10 when it is set (the counterpart of 0x2428c0, not read). Value 2 waits until the count +0x3e equals +0x3c (every slot done) and then calls 0x23211c on the record at +0xc with 1, the same reference step as [script-triggers.md](script-triggers.md) ("AI spawner, kind 14, +0xc") that fires the `TriggerObject` reference, and sets the state to 0. The port registers that reference but never calls the step for a spawner (SCRIPT-359). Where +2 is set, and the counters +0x3c, +0x3e, +0x40, +0x42, were not traced.
- Not read: the spawn conditions, the delay parameters (0xb2509a04 = 2.0, -1.0 or 1.0 per spawner; 0xc10fcf22 = 5.0 or 0; RespawnTime 0xcc4d0f37 = 0 in all), what makes a slot "done" (a defeated or arrested character), and the GoTo targets' use.
