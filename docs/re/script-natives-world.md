### Argument arrays

A script argument array holds the object as the first element and every following argument two words later: the second argument is at `[r1 + 0xc]`, the third at `[r1 + 0x14]`, the fourth at `[r1 + 0x1c]`, the fifth at `[r1 + 0x24]` (EffectFadeObject, EnableDistanceFade, SetPartyCharacter read them so; the strings of StreamRoomIn and AddToSemiTransNearCameraList are at `[r1 + 4]` and `[r1 + 0xc]`). SetPartyCharacter reads its second argument as an integer (`& 0xffff` of the stored word), the third as a float.

### DestroyProp and KillObject (0x1a2fe4)

- Handler: `r0 = 0x22dacc([r1])` (the object, with the player alias), `0x23cd80(r0, 0)`, return 1. 66 calls in the level files, KillObject 15.
- 0x23cd80(entity): returns when the halfword +0x10 has bit 0 (the disabled flag of EnableObject) or the word +0xc has bit 0x10 (destroyed). Otherwise 0x23211c(entity, 0, 1), the broadcast 0x23cee8 over the lists at 0x3775c0 and 0x3775c4 (and over the entity's own list of the scene, 0x23c188), then message 1 through the class message handler 0x244fc8(entity, 1, &0). A handler that returns 0 leaves `+0xc |= 0x10` and calls 0x2320f8 (drops the node) when `[+0x44]` is set; a handler that returns non-zero takes the destroy itself: the vehicle class handles message 1 as its break ([vehicles-damage.md](vehicles-damage.md) §2026-10-16, 0x159bd0), so DestroyProp on a vehicle breaks it and does not remove it.
- The broadcast 0x23cee8 is the one the trigger events use (queue 0x21a560 at its end); which listeners the lists hold is not read.
- Mission 1-2: `1-2_MissionStart` (hash 3389fe1c) calls `DestroyProp(1-4_Police_Car)`, then `EnableObject(1-4_Police_Car, 1)` and `EffectFadeObject(1-4_Police_Car, 0, 1, 1.2, 1)`. The car is disabled when the script runs (the port's state after the startup script says so, test `natives-world-real-data`), so 0x23cd80 returns at once: the call is a no-op there. Other uses in lvl_01 are crates, fences and skylights (`1-3_smash_crate`, `1-3_Fence_08`, `1-4_Showroom_Skylight*`), not in mission 1-2.
- Port: `ObjectNativeState::destroy` (src/runtime/natives_objects.cpp) and `PlacedObjectState::destroyed`; message 1 is queued as a class message; `ScriptRunner::setClassMessageHandler` lets the host take it (vehicles: `breakVehicleNode`).

### EffectFadeObject (0x288a60, tween registry 0x21b7cc, evaluation 0x1593c8)

- Handler: `0x229e54(object, flags = (int)arg4 & 0xff, 0)` with `s0 = arg1` (from), `s1 = arg2` (to), `s2 = arg3` (duration); 0x229e54 is a tail call of 0x21b7cc(scene = object+0x20, node = object+0x3c, flags, 0 = linked object). Calls in lvl_01: 21, flags 1 (20 times) and 3 (once); `from`/`to` are 0 or 1.
- 0x21b7cc (adds to [objective-hud.md](objective-hud.md) §2026-10-15T19:58): the entry table is at scene +0x1338 (count +0x1334), 28 bytes each: node, start time (0x23f74c), duration (+8), from (+0xc), to (+0x10), linked object (+0x14), flag byte (+0x18). An entry of the same node is reused in place. A full table (20) completes the entry with the greatest age first (0x1593c8 with the duration as elapsed time, which finishes it). The new entry applies `from`: the node is hidden when `from == 0` (0x23f734(node, 0)) and shown otherwise; flag bit 0 sets the node alpha to int(from x 255) (0x23f708), bit 1 the colour (0x2408f8 from the float3 at 0x56d40c, 0x23f6d0), bit 2 a third property (0x23f540).
- 0x1593c8(scene, index, elapsed) (the loop 0x2fbb7c calls it with -1.0, which means the time since the start, for every entry and removes the ones that return 1): when the duration is not 0 the value is `from + (to - from) x elapsed / duration`, 1.0 from 1.0 up, 0 at or below 0. Value 0: node hidden, linked object disabled; flag bit 0 sets the alpha to int(**from** x 255) for an ordinary node and to int(to x 255) for a particle node (node type word equal to the global at 0x3767e4 and name hash equal to the string "particles" at 0x1596c4); bits 1 and 2 use `from`. Other values: node shown, linked object enabled (message 251), alpha, colour and third property from the value. Finished (`duration <= elapsed`): when `to == 0` the node is hidden and the linked object disabled, the entry is replaced by the last one and the table shrinks.
- Port: `EffectNativeState` (src/runtime/natives_effects.cpp) keeps the tween per object name and the last state (`ObjectFade`: multiplier int(value x 255) / 255 for flags 1 or 2, hidden); `LevelSession::applyObjectFades` sets `Scene::setInstanceFade` and hides the instances. The tween clock steps by the update time from the next update on (as the waypoint tweens).

### EnableDistanceFade (0x2a05bc) and the fade it switches

- Handler (REA): `node = object[+0x3c]`; when `node[0] & 31` equals the global at 0x37674c (the type of a mesh node; zero in the file), argument != 0 sets bit 4 of byte `node+0xde`; argument 0 stores 16 in `node+0xdc`, clears bit 4 and stores 255 in `node+0xdd`. Then 0x2b65dc(child, argument != 0) repeats the same for every child node (links at +8 and +0xc). 89 calls over the levels, mission 1-2 and the startup use argument 0 (`Police_Plaque`, `FP_Ladder_01`, `Donut_Base_01`, `1-2_HideoutGate_Left`, `1-2_Dog_Cage`, ...).
- Creation of a mesh node (0x10d2d4, objdump): `+0xdd = 255` and bit 4 of `+0xde` set, so **every mesh node has the distance fade on until a script clears it**.
- The per-frame fade 0x10eb70(node, camera matrix) runs for nodes with the value 4 set in `[0x529dc8]` (0x000d0004 in the read), bit 9 of the node word and bit 4 of `+0xde`. The tier comes from the node's radius `node[+0x9c]`: below the float at 0x52a1d0 (3.0) tier 0, below 0x52a1d4 (6.0) tier 1, below 0x52a1d8 (12.0) tier 2, and a node with a radius from 12 up returns without any change (bit 5 of `+0xde`, set by DistanceFadeMid, forces tier 1). `s0` is the squared distance of the node's centre (`+0xa0`) from the position stored at 0x52a1b4 (881.28, 18.79, 1108.47 in the read, 2.2 above the player of that state; taken as the eye position) minus the squared radius. A node whose step byte `+0xdc` is not negative starts to fade out (`+0xdc = -16`) when `s0` reaches the square of the float at `0x52a1e8 + 4 x tier` (38, 76, 114); a node that is fading out switches to `+16` when `s0` falls to the square of `0x52a1dc + 4 x tier` (36, 72, 108). The alpha byte `+0xdd` moves by `+0xdc` each frame, clamped to 0..255; when the byte at 0x52a1cc is non-zero it jumps to 255 or 0 instead, and when 0x52a1cd is non-zero the step is forced to +16 (both bytes were 0 in the read). The draw 0x10bcc8 reads `+0xdd`: below 255 it takes pass 2 instead of pass 1 (taken as the translucent pass).
- The same tiers scale target ranges: 0x28781c(node) returns -1 (bit 4 clear or bit 9 clear), 1 (bit 5 set), else tier 0 to 2 or -1 beyond the third threshold; the AI target scorers 0x2df0dc and 0x2ee214 index the tables at 0x52a1dc / 0x52a1e8 with it.
- Port: `EffectNativeState::enableDistanceFade` records the last value by object name; nothing draws it, so every mesh stays opaque (RENDER-66). The node kind gate and the child recursion are not modelled (SCRIPT-57).

### AddToSemiTransNearCameraList (0x2cb734, entry 0x1f40d8)

- Arguments: the model name (first) and an entry name (second, always "" in lvl_01: `Prop_Waypoint_Small`, `_Large`, `_LCPDBadge`, `_ChequeredFlag_Small`, `_ChequeredFlag`, all in the startup script). - 0x1f40d8(list, model, name, flagA, flagB): finds the entry with the same model position (compares the matrix translation) and name, or allocates 0x2d bytes + the name length: model at +8, name pointer at +0xc, `s16 -1` at +0x10, `u16 255` at +0x12; sets bit 1 of byte +0x15 when flagA and bit 2 when flagB. The native passes (0, 1): bit 2, "near camera".
- The draw side that reads the list is not read; `AddToSemiTransList` 0x2a059c (2 calls) and `AddToSemiTransListBound` 0x2c08e8 are the other callers of 0x1f40d8's sibling and not part of this entry.
- Port: `EffectNativeState::addSemiTransNearCamera` records (model, tag) once per pair; nothing draws it (RENDER-67).

### StreamRoomIn (0x1bfba4), the request list and the consumer

- Handler (objdump): `name = *[r1 + 4]`; scene = `[0x376c78]+0x28`; for each room `n` of the scene's room array (`+0x1320`, count `ushort +0x131e`) the room's name `[room+0x1c]` is searched for `'.'` (0x249b00); a hit's text after the dot is compared with the argument (0x25ad90, equal means 0). - 0x20f194(room): `list = *0x375d70; list[1 + list[0]] = room; list[0]++` (a 132-byte buffer: 0x309584 allocates it, 0x309564 frees it). 0x309534 and 0x30954c (referenced from the table 0x363e90 at slots 0x363eb8 and 0x363ee0) set the count to 0; who calls them is not read.

- 0x2b9cf8 walks the list each update and calls 0x205b5c(room, request) with byte 0 = 1 (the rest of the word from the room's own flags, bytes 1 and 2 set by 0x2297b0 / 0x236104), so the room loads like a neighbour with priority 0.
