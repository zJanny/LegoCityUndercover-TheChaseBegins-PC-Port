The reason is the second cell search.

**Second cell search 0x164328 (cell, point).** In the push-out loop of 0x1c54f8 a point below its cell's plane by more than 0.1 (the float compare `0xbdcccccd < (uint) depth`) whose cell has flag bit 0 (cell +6) calls 0x164328; a result below 0 drops the point (no push-out), else the plane of the found cell replaces the cell's and its depth is recomputed. 0x15c4a4 does the same for a start point below the plane (before its contact test) but keeps its cell when nothing is found. 0x164328 calls 0x1aa478 (0.3 = 0x3e99999a, point, cell, list of up to 0x80): the cells reached from the start cell across edges whose xz segment passes within 0.3 of the point (distance of the point from the edge's line below 0.3; along the edge, beyond its ends the distance to the end corner at most 0.3), the start cell first; per cell the first that is not the start cell, has |plane y| below 0.2 (0x3e4ccccd, a wall) and surface byte other than '$' and holds the point in the projection of 0x2384dc is the result. 0x2384dc picks the two axes from the plane normal (|x| < |z| and |y| < |z|: z, axes (1,0) for z < 0 else (0,1); |x| < |z| and |y| >= |z|: y, axes (2,0) for y > 0 else (0,2); |x| >= |z| and |y| < |x|: x, axes (2,1) for x < 0 else (1,2); else y as before) and calls 0x158cb8, three side tests of the point against the corners in those axes. With no wall cell near the point (the street below the overhead layer) the search returns -1 and the point is dropped.

**The vehicle bump pass 0x2d4af0.** For a vehicle body whose broadphase mask holds bit 1 (static group) and whose flags +0xc4 have bit 0, with a speed above 20 (0x41a00000) and the cool-down body+0x194 expired, it asks 0x33aa1c (the entities within entity record +0x208 plus dt of the body's position in the grid 0x578dfc, flags +0xc4 & 0xffff, record flags +0xcc without 0x80, not itself) for neighbours, tests the swept sphere of radius +0x208 + 1.5 against each neighbour with a physics body and a broadphase handle that passes the group test 0x2d4224, intersects the swept body box with the neighbour's box (0x1bfd24, margin 1.5), and then sends both entities the contact message 0x80000002 (0x271764) and exchanges impulses by the masses +0x15c (0x1bfff8); only bodies with a handle in the Bullet world qualify (vehicles). Not ported.
