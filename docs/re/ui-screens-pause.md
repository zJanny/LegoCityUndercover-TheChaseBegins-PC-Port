**Open 0x21377c(count, texts, selected).** 0x20ee2c (shows the round menu layout when +0xe5 is 0 and replays its TransitionOn when +0xea is 0; on the pause screen both are 1 because the Options page leaves with 0x20eec4(1, 0), which keeps +0xea, so nothing happens there); count +0x8e9; `Blockbuster_On` from its first frame; state 2; first row 0, selection = the argument, then first += 10 while the selection is at or past first + 10. Every tile and old tile: shown, no row, portrait cleared (0x234b90), tile `Show` and `default` (old tile `default`) from the start. Every row below the count: text from the list or empty, rows first..first+9 on tiles 0..9 with their pictures, enabled 1, locked 0, new 0 (gift is kept). Then the texts 0x20ed0c and the two shortcut callbacks.

**Texts 0x20ed0c.** `Text_ItemName` = the selected row's text, or " " with no selection; pages = (count - 1) / 10 + 1 (byte arithmetic); with more than one page `PageNumber` = "%d/%d" (page + 1, pages), else empty. **Row text 0x213624** stores the text and refreshes the texts when the row is selected; **row picture 0x213558** loads the picture into the row (+0x84) and onto its tile when the row is shown (tile of a row: 0x2ae038, -1 when not shown).

**Update 0x1dad8c** (returns 1 for A, -1 for B, 0). The tile of the selection is looked up first. State 2 with `Blockbuster_On` ended (0x245f84 = 6): state 1, the selected tile plays `outlined` and `pressed`. State 3 with `TransitionOn` ended: state 0. In state 0 with the release flag: the ten portraits are cleared and the row pictures freed, flag 0. Page = first / 10, pages as above. A = +2, B = +1. Only in state 1: pad slot 4 (A) press → A; else slot 5 (B) → B; else slot 3 (Right) while count > first + 10 → next page; else slot 2 (Left) while first ≥ 10 → previous page; else the touch: for each tile with a row, 0x20a410(1, portrait +0xf0, portrait width × 0.5) (touch phase 1, the first update of a touch, within the radius): the selected tile gives A (with +0x8f0), another tile selects its row (selection = first + i) and clears the row's new flag (+0x8ef = 1); then the left arrow (page not 0) and the right arrow (not the last page) with radius = the arrow width (no halving) turn the page. A is cleared when the selected row is not enabled (with no selection the byte read lies in front of the row array). A page turn calls 0x292018; otherwise a changed selection without A plays sound 0x12, `default` on every other tile, `outlined` and `pressed` on the selected one, and refreshes the texts. Every update, in every state: a tile with a row gets the portrait tint 255 (enabled) or 100 grey (0x20a330), locked, new and gift opacity 1 or 0 by the row bytes, BG 1; a tile without a row gets locked, new and gift 0 and BG 0.5 (0x24d0a8 clamps the node opacity +0x20); an old tile without a row gets locked 0, new 0 twice and BG 0.5 (its gift is not set). Left_Arrow fades in at 10 per second (literal 0x1db798, times the frame time 0x23602c) while the state is 1 or 2 and the page is not 0, else out; Right_Arrow the same while the page is not the last; both clamped to 0..1 and using the page from before the input. +1 and +2 are cleared.

**Page change 0x292018(direction).** Sound 0x18; first += 10 × direction; texts; every tile and old tile: all storyboards stopped (0x252828); the old tile takes the tile's row and picture, the tile the row first + i (or none past the count); each of them plays `outlined` and `pressed` placed at their end (frames 0xffff, 0xffff) when its row is the selected one, else `default` at its end; then `Blockbuster_LeftMove` (direction > 0) or `Blockbuster_RightMove` from the start. In the layout the move slides `itemSmallGroup` in from x 314 (or -336) while the old tiles sit at x 0 (or 650) relative to their places 314 pixels to the left of the new ones, so the old page leaves to the left (right) as the new page enters.

**Close 0x1e87d0(roundMenuStays, release).** Nothing in state 0 or 3. Plays the layout's `TransitionOn` from its start (it hides `itemSmallGroup`, `Pageslots`, `Item_Name` and fades `Backgrounds` in from 0 over 0.4 s); without the first argument also 0x20eec4(0, 0) (round menu close); `Hide` on tiles 0 .. min(count, 10) - 1; state 3; +0x8ee = release. The Languages page calls 0x1e87d0(1, 0) from A and from its leave request.

**Users on the pause screen.** The pause update 0x300378 runs both the round menu update 0x1f08d4 and 0x1dad8c and uses the grid's result while 0x20fd0c (state not 0) answers; +0x33c takes 0x20fcf4 (the grid's selection) then. 0x1fbedc (state 2 or 3) is one of the page manager's busy tests.

**Layout values** (chase-layoutdump): `itemSmallGroup` at (0, -10); tiles `itemSmall_0..9` 128 by 128 in two rows, column by column (0 top left, 1 below it, 2 top of the second column …) at x -7, 43, 93, 144, 194, the upper tiles at y -1, 27, -2, 27, -2 and the lower ones at y 57, 86, 56, 85, 56; portrait (32, 32) 64 by 64 in the tile; `Pageslots` (59, 163) with `Left_Arrow` (-57, -68) and `Right_Arrow` (239, -68, scale -1), 16 by 32; every element has origin 0.5, 0.5. Storyboards: Blockbuster_On 0.4 s, TransitionOn 0.5 s, the two moves 0.4 s; itemSmall Show 0.24 s, Hide 0.2 s, pressed 0.5 s, outlined and default 0 s.

**Port.** `chase::runtime::ItemGrid` (runtime/item_grid.*) with open, row text and picture, close, update and page change as above; the layout storyboards go through the round menu's storyboard list (`RoundMenu::startStoryboard`, the same layout's player), the tile storyboards are kept per tile and drawn through `LayoutScene::referenceLaterStoryboards`; `frontend/item_grid_view.*` reads the lengths and click areas from the layouts and adds the tiles, pictures, opacities and texts to the round menu's scene. `PauseMenu` opens it for the Languages page with nine rows and no selection, the row names and flag pictures, closes it with (1, 0) and waits for it in the page manager. Stand-ins (UI-S15): the hit centre is taken as the element's centre; A without a selection does nothing; the grey tint of a disabled row is not drawn. Tests `item-grid` (rules), `item-grid-real-data` (layout values and the drawn flags), `pause-menu` (the Languages page in the grid).

Unknowns: whether node +0xf0 is the pivot (the element centre with origin 0.5) or its top-left corner, so the exact click areas; what the original does with A while no row is selected; the meaning of the colour byte +0x67 that 0x20a330 clears; whether the grid's `TransitionOn` (+0x18) is the same storyboard object as the round menu instance's (+0x20) — the port treats it as one; the picture and timing of the open, the page move and the close (the background fade of the close) against the oracle; the shop and other pages that use the grid (UI-11).
