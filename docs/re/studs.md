# Studs (collectible coins)

How the level's stud objects are created, drawn, collected and counted. Replica: `StudObject` / `drawableObjects` (src/assets/level.cpp), `StudField` (src/runtime/studs.*), `StudSprites` (src/render/studs.*), wiring in src/game.cpp. Level objects in general: [objects.md](objects.md).

## Current state

- Stud classes are pickup objects (object type 0x3d, `pickuptype` 0 silver, 1 gold, 2 blue, 3 purple), drawn as camera-facing sprites from `Pickups_commonstud.tga`, never as models. [§2026-10-13T17:09](#ts-20261013-170941)
- The record (0x4c bytes) sits 0.56 above `initialposition`; `DisabledOnStartUp` hides it until a group sequencer enables it. [§2026-10-13T17:09](#ts-20261013-170941)
- Sprite frame comes from a clock of 3000 ticks per second (15 frames per second); quad half size 0.19, tint per type. [§2026-10-13T17:09](#ts-20261013-170941)
- Pickup rule 0x180168: 3D distance from the stud to the player's pickup point (offset (0, 1.153, 0.08)) below radius 1.5; the skip counter limit is 30 (not 17). [§2026-10-13T17:09](#ts-20261013-170941), [§2026-10-13T21:35](#ts-20261013-213500)
- Collecting flies the stud to the HUD sink for 1.0 s (step `(target - pos) / (30 * timer)`), then adds 10 / 100 / 1000 / 10000 (times the multiplier mask) and sets the HUD bar. [§2026-10-13T21:35](#ts-20261013-213500), [§2026-10-13T17:09](#ts-20261013-170941)
- The collect sound is played: 64 for silver and gold, 63 for blue and purple. [§2026-10-13T21:48](#ts-20261013-214838)
- A car that destroys a traffic light (type 204) or a wobbly tree (type 119) releases bricks only: no dropped stud (0x21e2e4 modes 0..2, 0x23a6b0, 0x2149ac, 0x22ca88 not entered). [§2026-10-18T19:57:26](#ts-20261018-195726)
- Dropped studs are the records 0..19 of the pickup pool: 0x21e2e4 mode 0 counts blue (100), gold (10) and silver (1) out of the count, mode 1 is mode 2 (a heart first) one time in three, else mode 0; at most ten records, none for count 0. They fly at 0.5 up and (r - 0.5) x 0.1 sideways, fall 0.05 per update, bounce with 0.3 (landing sound 65 at most every 60 updates), rest, live 8.5 s and blink below 2.125 s; the skip counter starts at 30. Ported (`StudDropField`); the callers (wobble hit, hit-sequence slots, car break, player hurt, behaviours) are not wired. [§2026-10-19T14:02:59](#ts-20261019-140259)
- Open: groups and `GroupOrder`, magnet, the callers of the stud drop and the dropped heart, multiplier mask, clock origin, radius for other characters, gold/blue/purple recorded pickups.

**Constructor 0x17f8e0 (objdump).** The record is 0x4c bytes in a pool (`*(*(*(*0x376c78 + 0x28) + 0x10) + *(0x58ef1c + 0x1c) + 8)`, in the oracle 1130 records at 0x8dec3d0). It stores: position = initialposition with y + 0.56 (literal 0x3f0f5c29), +0x44 state 1, +0x45 a category byte (u16 at +14 of the class lookup 0x22d64c, plus 1), +0x46 = `pickuptype`, and reads `DisabledOnStartUp` into +0x32/+0x34 and `GroupOrder` into +0x33/+0x35; a non-zero `DisabledOnStartUp` sets the state to 0 (hidden until a group sequencer enables it, 0x28a2cc). **Drawing.** 0x17fc38 (ev_651a36a2…cfbb4) per frame: frame index = bits 6..9 of `(clock * 0x51eb851f) >> 32`, `clock` = `*(*0x37750c)` evaluated through 0x256af4; u = (index & 3) * 0.25, v = (index >> 2) * 0.25 (stored in 0x58f580..0x58f58c, shared by every pickup). ## 2026-10-19T14:02:59+02:00 — Dropped studs ported: the burst 0x21e2e4 modes 0..2, the spawner 0x19913c, their update in 0x180168, the draw rule of 0x17fc38 and the request of 0x2149ac (llvm-objdump of artifacts/game/game.arm.elf; no emulator, no REA run)

Method: `llvm-objdump -d --triple=armv6k --mattr=+vfp2`, read instruction by instruction: 0x21e2e4..0x21e6fc, 0x19913c..0x199ad8, 0x180168..0x180c94, 0x17fc38..0x180164, 0x2149ac..0x214bdc, 0x23a6b0, 0x2277c4..0x2278fc, 0x28a128..0x28a2c8, 0x28a4b0 (head), 0x2ed0b4..0x2ed4b8, 0x254250, 0x219178, 0x22f770; trig helpers as named in [cutscenes.md](cutscenes.md) and [skeleton-animation.md](skeleton-animation.md) (0x24765c / 0x2473ec atan2f(y = s0, x = s1); 0x235dc0 tail-jumps to the sine 0x247ac8, 0x247f00 to the cosine 0x247c90). The bricks of mode 3 are in [debris.md §2026-10-18T14:40:56](debris.md#ts-20261018-144056); this entry adds what differs for the stud records 0..19.

**0x21e2e4 arguments.** r0 mode, r1 count (descriptor +0xe, halfword), r2 position, r3 direction, s0 spread, s1 (unused here), stack words: 0 (unused), 1 a flag (non-zero: 0x19913c gets r3 as its velocity argument), 2 a byte pointer that receives the first chosen index, 3 and 4 passed as r2 and r3 of 0x19913c, 5 a float passed on the stack. Mode 1 draws one word first (0x21e6b0) and becomes mode 2 when it is a multiple of three (`umull` with 0xaaaaaaab), else mode 0. Records 0..0x13 for modes 0..2. Then the record choice and the raw draw at +0x10 as for the bricks; the descriptor flags +0x1e take bit 0 from byte 0x377278 and bit 1 from 0x37727e, which is cleared after the call (0x21e6e8). Direction: with x or z not 0 the halfword +0xc = int((atan2f(x, z) + pi) x 64 x 0.3183099) (literals 0x40490fdb, 0x42800000, 0x3ea2f983), else 255; 0x19913c turns it back into (sin a, 0, cos a) x `*0x37728c` with a = h x pi / 64 - pi.

**0x19913c for modes 0..2.** r1 = velocity (or 0), r2 = skip counter (sign-extended halfword stored into +0x30), r3 = a byte pointer. start = position + direction x 2.5, end = start - 10 in y, the wall test 0x22b108 and the ground test 0x21ab20 as for the bricks; the ground reference is the start (mode 3 alone lowers it to the end y), so a missed ground test gives start y - 20 + 0.56. The loop is entered at its test (0x199a7c): while the count is not 0 and fewer than ten records were done. Per record: state 2, life 8.5, +0x49 bits 0 and 1 from the descriptor, +0x30 = r2, position, plane index; velocity = *r1 when given, else x = (dir x + spread (r - 0.5)) x 0.1, y = 0.5, z likewise (draws for x, then z), all times the scale; +0x38 = rest height - 0.05, the ground test 2 units ahead as for the bricks.
