On an overlap: bit 0x1 slides the move (0x22f928: when n . move < 0, move -= n (n . move), on a copy, then x and z are written, y too unless bit 0x2); bit 0x2 first sets n's y to 0, normalises (0x257ea0) and puts the old y back when |y| < 1.0 (bits below 0x3f800000); the count grows; without 0x1 and 0x8 the first overlap ends the walk. Bit 0x8 swaps a missed entry for the last one (the ground probe of [collision.md](collision.md)).

**0x287ac4(mover, move, entry, filter, mode, s0, s1)** = 0x208d84(entry as collider, the mover's world box 0x230088 (0x22ec3c of +0x60 / +0x6c under the node matrix), no frame, move, filter, mode, 0, mask 0, s0, s1) != 0. **The turn branch of 0x1f49d8** (a move whose fourth float is not 0, a mesh hit and slide): with N the owner's node matrix, r = the mover's translation in N's frame (0x2536c0), t = cross(unit r, N row 1) (0x23b998, 0x23b960), e = r turned about y by the turn (0x17e3c0 with sinf 0x247ac8 and cosf 0x247c90: x' = x c - s z, z' = z c + s x) minus r, v = t (e . t) (0x2408f8) rotated by N (0x20b214); 0x23d434(mover, v, 92, 17, *0x376910, 0.0), the mover's node moves by v's x and z and is set (0x24c118). 0x1f49d8 is called only by 0x2baef0 (0x2baf6c, 0x2bb038, 0x2bb0f0), and 0x2baef0 only by 0x2c0bb4 and 0x2c8ffc with the move of their caller, which is (move, 0.0) ([§2026-11-12T08:17:17](#ts-20261112-081717)): the branch never runs for a traffic car and is not ported.

**0x27f174(mover, move, box centre, box half, matrix, mover centre c, moved centre p, slide).** q = p in the matrix's frame (0x2536c0) minus the box centre; R = box half + the mover's +0x6c. Not -R < q < R on every axis: 0. Without slide: 1. With slide, s = c in that frame minus the centre:

Then 0x23d434(mover, move, 92, 1, *0x376910, 0.0).
- else, for each axis: s >= R adds row x ((R - q) + 0.007), s <= -R adds row x ((-R - q) - 0.007) (0x27f654). Then 0x23d434(mover, move, 92, 3, *0x376910, 0.0).
