The loop is entered at its test (0x199a7c): while the count is not 0 and fewer than ten records were done. Per record: state 2, life 8.5, +0x49 bits 0 and 1 from the descriptor, +0x30 = r2, position, plane index; velocity = *r1 when given, else x = (dir x + spread (r - 0.5)) x 0.1, y = 0.5, z likewise (draws for x, then z), all times the scale; +0x38 = rest height - 0.05, the ground test 2 units ahead as for the bricks. Mode 2: type 4 (heart), no change of the count, the mode becomes 0 for the next records. Then with +0x49 bit 1: x and z times 6.0 (0x199ad4) and the vector times 0.1; y times the type's gravity +0x80. **So a count of 0 drops nothing, not even the heart of mode 2.** Records 0..19 never get +0x1c, +0x22, +0x24 or +0x45 from this code (+0x45 stays 0 from the zeroed allocation).
