**PlayAnimation 0x268240** (asm read): mode = the low byte of the raw argument word 3 (no float conversion; the port reads the argument as a number as for the other raw-word natives, [script-natives-progress.md](script-natives-progress.md)), speed argument 2, blend argument 4, then `AnimationOffset` through 0x2451d0 (the int/bool parameter lookup) applied by 0x22c2fc when not 0. **Waits 0x2a06a8 / 0x263ae4**: slot 0x233900(entity + 0x40); none or no animation -> done; kind (0x245f84 = 0x22f560 of the animation's slot) 6 -> done; kind 1 or 5 -> done when `|length (0x23caa4) - position (0x213140)| <= 1.0` (float bits compared with 0x3f800001); every other kind (0 still playing, 2, 3) blocks. **AttachToBoneRot 0x1bf718.** Builds the matrix with 0x24d434 (identity) and 0x237c48 from the three angles times 0.017453294 (the placement rotation `assets::placementMatrix` already uses: row 0 = (cy cz, sx sy cz + cx sz, sx sz - cx sy cz), row 1 = (-cy sz, cx cz - sx sy sz, sx cz + cx sy sz), row 2 = (sy, -sx cy, cx cy); 0x249038 stores sin then cos, 0x247ac8 / 0x247c90), calls 0x20f33c(parent, child, bone name, matrix), then sets bit 0x40 of the child's flags +0x10 when the child's node parent equals the node of the parent's owner (`**(parent+0x20+0x24)+0x3c`, not read further).

**0x20f33c.** (1) The child's node (`child+0x3c`) is unlinked when it has a parent (0x245048; the bone record at node+0x10, when set, is released with 0x2558e8 / 0x242814(node, 0)). (2) The bone is found by name in the parent's animation player (0x24f444 walks the 0x98-byte joint records of the skeleton and compares the names) and 0x227788 copies its bind world matrix (record +8). (3) The argument matrix is copied (0x258858, 64 bytes) and 0x23d39c adds the xyz of the bone matrix's translation row to the xyz of the argument's translation row: **the local matrix is the argument's rotation with the bone's bind translation; the bone's bind rotation is not used.** (4) 0x24c118 stores it on the unlinked node. (5) 0x22690c links the node under the parent's node (not 0x245008: the local matrix is not recomputed from a world pose; it sets flag 0x1000 on the child and its children). (6) 0x2023bc(player, joint) allocates a 0x38-byte record of the type created in 0x1036f0 (DAT_0037675c; fields +0x30 animation player, +0x34 joint index) and 0x242814(node, record) stores it at node+0x10 and puts the node on the global list 0x5303b8; 0x2268f4(parent node, 1) clears flag 0x100 of the parent.
