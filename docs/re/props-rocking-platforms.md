**The path pose (update 0x2807c8 with R+0x50 set, after the shaped value s).** p = 0x22a4c0(path, s) when `ConstantSpeed` (R+0xb8 bit 1), else count x s (u16 path+2; count, not count - 1). **0x22a4c0(path, t).** |t| (a negative t is negated); no points: 0; t with bits 0x3f7fffff or 0x3f800000: count; bits below 0x34000000: 0. Otherwise the cumulative lengths (path+0x14, built on each call when it is null, which it is in the level data: entry 0 is 0, entry i adds slot 1 of the type (0x293540 for type 0) with 20 steps per segment from point i - 1 to i, count + 1 entries on a closed path), target = fmod(t, 1) x total, and a binary search over 0 .. count - 1 for the entry pair around the target: the result is i + (target - L[i]) / (L[i + 1] - L[i]). This is the function the detective footprints use with 10 steps ([abilities-detective.md](abilities-detective.md)).

**0x270c60(path, out, p), a squad.** No quaternions (path+8 null): the identity. An open path clamps p to 0 .. count - 1; i = floor(p), j = i + 1, f = p - i; a closed path with at least 3 points wraps i by the signed remainder plus count and keeps j unwrapped (the tables have count + 4 entries, the last ones repeat the first with the sign flipped); any other path limits j to count - 1. q1 = slerp(Q[i], Q[j], f), q2 = slerp(C[i], C[j], f), out = slerp(q1, q2, 2 f (1 - f)), all with mode 2, normalised by 0x1ff9cc. Q is the block of the path record +0x10 (path+8), C the block after it (record +0x14, path+0xc), both 16-byte quaternions from block offset 0x40; the C++ loader now reads C as `LevelPath::orientationControls`.

**0x21a600(out, a, b, mode, t).** dot = a.b summed in the order x, y, z, w. Mode 2 keeps the sign; any other mode negates the dot and b's weight when (dot < 0) differs from the mode (mode 0: the shortest way, as 0x270b70 uses it). A dot whose bits exceed 0x3f7fff58 blends with 1 - t and t; otherwise theta = acos(dot) (0x21bbb8) and the weights are sin((1 - t) theta) / sin theta and sin(t theta) / sin theta (0x235dc0). 0x248870 makes the rows 1 - (yy + zz), xy - wz, xz + wy / xy + wz, 1 - (xx + zz), yz - wx / xz - wy, yz + wx, 1 - (xx + yy) and leaves the translation alone.
