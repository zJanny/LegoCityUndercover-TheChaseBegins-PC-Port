# QoL PC controls

## 1. Scope

Escape that is consistent and never closes the game, and the overhaul of the controls so that the game plays like a typical PC game on foot and drives like a typical PC driving game. Plan: [qol.md](../qol.md). A QoL feature with its own "PC controls" toggle on the Quality of life tab (on in Improved, off in Original); with it off the faithful 3DS mapping of [input](input.md) holds. The Escape rules apply in both modes. Design: [qol-controls.md](../../design/qol-controls.md). The settings menu and its Controls tab are [qol-settings-ui](qol-settings-ui.md).

## 3. Verified behaviour

PC controls toggle and on-foot set pinned by test `qol-pc-controls` against the design entry (original mode first: no file written, `config/controls.cfg` untouched; Original off, Improved on, Custom own mix; the layout key by key; the running input; toggle through the settings menu; rebinds and Reset kept per mapping). Escape (QOLCTL-1) and Quit game (QOLCTL-5), tests `escape-binding`, `qol-ui-page-game`, `qol-ui-menu`, `qol-quit-event`, `qol-pause-entry-real-data`: Escape is a fixed second binding of Start in `chase-game` (`InputState::fix`), never a quit; Quit game asks "Quit the game?" with Yes and No (focus on No), Yes pushes `SDL_QUIT`, No, Escape, pad B and a click on No cancel. Mouse camera (QOLCTL-6), test `qol-pc-mouse-camera`: with the toggle off the cursor is never captured and no motion turns; on, a captured cursor adds mouse X as an analog R value to the follow camera's shoulder turn (same camera yaw as R in proportion; left is negative; Y gives nothing; Invert camera flips it); a menu (pause screen or settings menu) drops the capture and the motion; a hidden pointer starts at the real cursor, follows the relative motion and, entering the lower-screen rectangle, releases the capture and puts the real cursor there; moving the cursor out captures again; a held mouse button never starts a capture (a touch drag); the lower screen hidden in Improved never releases. Left button Y, middle button L and R, right button unused: already pinned by `qol-pc-controls`. Escape on the pause screen (QOLCTL-12), test `escape-pause-pages`: play keeps Start; every page of the open pause screen takes B (the main wheel resumes with the back sound, Options and Languages go back one page, a second Escape closes), and a held key keeps its button until released. Every behaviour is tested first in original mode (all QoL off, the port's tests unchanged), then with the feature on ([qol rules](../../rules/qol.md)).
