# QoL true full screen

## 1. Scope

The top screen as the whole window: the 3D view widened up to 16:9 (same vertical field of view, more world left and right; wider windows get black side bars), the HUD anchored to the corners of the 16:9 area, the edges checked for pop-in. While the bottom screen shows, the widened view fills the full window width at the rows of today's top screen ([qol-screen-layout.md §2026-10-29T11:42:22](../../design/qol-screen-layout.md#ts-20261029-114222)). Plan: [qol.md](../qol.md). Toggle: own switch in the settings menu ([qol-settings-menu.md](qol-settings-menu.md)).

## 2. Status

IN_PROGRESS, opened 2026-10-28T09:21:35+01:00. The geometry, the render capability (QOLFS-7) and the hook (QOLFS-8) exist: with the toggle on, the 3D view and the glow pass use the widened region over the whole window, because the widened view hides the bottom screen in every preset (the user, 2026-11-02); with the toggle on each HUD part is drawn at its corner rectangle, at the picture's corners while a 5:3 camera shows (QOLFS-19; `src/qol/hud_hook.*`, `src/qol/hud_parts_hook.*`, QOLFS-2, QOLFS-13); the head icon and the scanner overlay stay on today's top rectangle. Only the gameplay camera widens; the cutscene, director and scanner cameras and movies keep the 5:3 region (QOLFS-18, QOLBOT-29). The config load hands the settings to the active store at startup and after F11 (QOLFS-11). The window has its 400x240 minimum from creation (QOLFS-10). With the toggle on the room request also loads the rooms of the 16:9 strip that the 5:3 view does not reach, up to the far plane (QOLFS-20).

## 3. Verified behaviour

Window size to game view rectangle, bars and aspect, and the corner anchors of the HUD are pinned by hand-computed values (`qol-view-layout`). The region of the 3D view equals today's top screen with the toggle off and is widened above the bottom screen with it on (`qol-view-hook`). The room request is the original's with the toggle off and adds exactly the strip rooms with it on (`qol-room-request-hook`; in Cherry Tree Hills Room20 at 164.98 m, `qol-room-request-game-strip`). Every behaviour is tested first in original mode (all QoL off, the port's tests unchanged), then with the feature on ([qol rules](../../rules/qol.md)).
