# Script system: missions, mission 1-3 at the garage

## 1. Scope

The garage part of mission 1-3 in `chase-game`: the key the detective dirt mound reveals, its pickup, the key use at the keyhole and the garage door, the parts crate carried to the base plate and the generator. The way from the generator to the mission end is in [script-system-missions-1-3-end.md](script-system-missions-1-3-end.md).
