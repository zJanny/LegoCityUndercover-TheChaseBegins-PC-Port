# Script system: missions, mission 1-3 at the garage

## 1. Scope

The garage part of mission 1-3 in `chase-game`: the key the detective dirt mound reveals, its pickup, the key use at the keyhole and the garage door, the parts crate carried to the base plate, the generator and the mission end. Split from [script-system-missions.md](script-system-missions.md); the roof, the super brick and the helipad of mission 1-3 are in [studs-super-bricks.md](studs-super-bricks.md) and [level-objects-buildit.md](level-objects-buildit.md), the carry classes in [level-objects-carry.md](level-objects-carry.md).

## 2. Status

IN_PROGRESS, updated 2026-10-26T16:06:43+01:00. The generator script runs in the port within one update of the oracle (658 updates from its start); the crate placing is measured and the port runs the target script one update early (SCRIPT-376). The key `1-3_Garage_Key` can be picked up: it is a carry object whose zone comes from its class mesh, the green arrow above it is the carry arrow every free carry object has, and after the pickup the arrow moves to the keyhole, as in the oracle (CTest `game-key-pickup-1-3`). Where the user's save state stands (1.71 from the key) A does nothing in the original either. Placing the key starts `1-3_Garage_Key_Base_Script`, which enables the key switch; A on the switch fires `1-3_Garage_Key_used` through the switch base and the garage door opens (CTests `game-garage-key-1-3`, `game-key-use-1-3`); the player steps and turns to the switch's use point and plays the key-turn clip, whose event sets the switch's use bit, with the oracle's update counts (SCRIPT-367, oracle check of the steps SCRIPT-369); a use marker shows at the switch while it can be used. The parts crate runs from its break to the build of `1-3_Pull_Switch_Bits` (the crate breaks in two hits, `1-3_Got_parts` enables the big carry object, A picks it up, A at the base plate places it and the build-it, hidden until then, builds; CTest `game-parts-crate-1-3`). The generator scene runs on the real path: A on the pull switch `1-3_Generator_Pull_Switch` (the final prop of that build-it) starts `1-3_Generator_Script`, which waits for the crane platform (103 updates, as in the oracle), stops the girder's rocking, starts the smoke of PlayParticlesGO, lets the girder guy jump down and ends with QuickSave (CTest `game-generator-1-3`); the platform and the girder do not move down, so the scene's camera shows the sky (SCRIPT-373). The script does not end the mission: the end, `1-3_Start_Rescue_Lawnmower_man`, lies behind the ledge platform, the push cart and the crane build-it, which the port cannot pass yet (SCRIPT-372).
