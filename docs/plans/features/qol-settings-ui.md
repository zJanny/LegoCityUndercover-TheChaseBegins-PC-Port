# QoL settings menu: modern PC menu

## 1. Scope

The redesigned PC settings menu: a full-window overlay with top tabs, bundled font, crisp text and widgets at the window's real resolution, shared mouse and keyboard focus, and its dialogs (reset, binding conflict, keep settings). It replaces the drawing of [qol-settings-drawing](qol-settings-drawing.md); the models and stores of [qol-settings-menu](qol-settings-menu.md) and [qol-settings-tabs](qol-settings-tabs.md) stay. Plan: [qol.md](../qol.md).

## 7. Code and tests

- Font and licences: `third_party/fonts/NotoSans-Regular.ttf` (Noto Sans Regular, hinted), `third_party/fonts/OFL.txt`, `third_party/stb/stb_truetype.h` (rasteriser, MIT or public domain); sources and commits in `REUSE.toml`. The binary-file check admits only `third_party/fonts/*.ttf` (user decision 2026-10-30). Test `qol-bundled-font` (`tests/qol/bundled_font.cmake`).
- `src/render/ui_font.*` and `ui_text_layout.*` (library `chase_ui_font`, no OpenGL, usable as a measure callback): `uiTextWidth`, `uiFontMetrics`, `uiKerning` (GPOS kerning through stb), `decodeUtf8`, `UiGlyphAtlas` (shelf-packed R8 atlas, one entry per code point and whole pixel size) and `layoutUiText` (quads of a line with per-glyph clipping). Pixel sizes are em sizes rounded to whole pixels. Test `ui-text-core` (`tests/ui_text_test.cpp`).
- `src/render/ui_text.*` with `shaders/ui_text.vert.glsl` and `ui_text.frag.glsl` (in `chase_render`): `UiText::draw` queues text (string, pixel size, position, colour, optional clip) and `flush` paints it at window resolution. `UiDraw` owns one and draws `UiBatch::texts` through it (QOLSET-84); the menu itself is wired by QOLSET-79.
Done: `src/qol/ui_layout.*` (QOLSET-71: scale, tab bar, row column, scrolling, widget rectangles, hit test, slider mapping, dropdown popup, focus rectangles, palette with 4.5:1 check), test `qol-ui-layout` in `tests/qol/ui_layout_test.cpp` at 720p, 1080p, 4K, ultrawide and 800x600 with a fixed-width fake text measure. `src/render/ui_draw.hpp` (plain-type `UiDrawList`: fill, border, line, dim, text, clip stack; `UiBatch`, `UiDraw`), `src/render/ui_batch.cpp` (pure batching: rounded corner tessellation by `uiCornerSegments`, scissor runs, clip intersection with the window) and `src/render/ui_draw.cpp` with `src/render/shaders/ui_draw.vert.glsl`/`ui_draw.frag.glsl` (GL executor, library `chase_render`). Test `render-ui-batch` (`tests/render_ui_batch_test.cpp`, no GL context, no game data). Text commands keep their order against the shape runs (`UiTextRun::runsBefore`; a text splits a run); `UiDraw` draws them between the runs. Test `render-ui-draw-window` (`tests/render_ui_draw_window_test.cpp`): hidden SDL window with a GL 4.6 core context, `readWindowPixels` of `window.hpp`, shapes, nested clips, dim, text and its order; exit 77 without display or GL; run with `SDL_VIDEODRIVER=offscreen`. The text colour type is `UiTextColour` (bytes), the draw list uses the float `UiColour`. Planned: font under `assets/` or `third_party/` (QOLSET-68), text and primitives in `src/render/` with `.glsl` shaders, the models in `src/qol/` with tests in `tests/qol/`.
