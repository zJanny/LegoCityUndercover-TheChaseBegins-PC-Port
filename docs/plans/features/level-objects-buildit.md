# Level objects: build-its

## 1. Scope

Build-its (`props/prop_buildit`, object type 0x15): the use zone, the build with the action button, the final prop and the event that tells the story script the build is done. Mission 1-1 step 6 (`1-1_BI_DonutVanParts`) is the first user. Super build-its (`props/prop_superbuildit`, kind 98, with their holders of kind 253) are covered from the helipad of mission 1-3 on, with its fast travel pad (kind 227); the bricks of other classes are not covered. General object items are in [level-objects.md](level-objects.md).
