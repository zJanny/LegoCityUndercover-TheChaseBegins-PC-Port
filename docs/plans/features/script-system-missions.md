# Script system: missions

## 1. Scope

What a whole mission needs from the script system beyond natives and trigger events that have their own files: the object classes that start or trigger mission scripts, scripts without a known starter, and the mission-level comparison with the original. Mission 1-2 is the first one analysed. General items are in [script-system.md](script-system.md), natives in [script-system-natives.md](script-system-natives.md), the trigger pass in [script-system-triggers.md](script-system-triggers.md).

## 2. Status

IN_PROGRESS, updated 2026-10-25T11:25:18+01:00. The reference-trigger step 0x23211c is ported (all registering kinds in one list, activate and deactivate, owner events, messages 10 / 0xff / 0xfe, nav node requests) and the build-it runs on it; the classes that call it otherwise are open (SCRIPT-358, SCRIPT-359). FadeScreen fades the top screen only while the ShowDialogBG byte is set, both screens otherwise (SCRIPT-310 closed). The dog cage of mission 1-2 has its use marker and the release runs on to the mission end with the screen faded back in (SCRIPT-292, SCRIPT-293 closed). The two unnamed mission 1-2 scripts have no starter in the original build (SCRIPT-113 closed). Mission 1-2 was compared with the original (gap list in [scripts-missions.md](../../re/scripts-missions.md)): its scripts run (`1-2_MissionStart` ends one update later than in the original), 12 of its 22 triggers are fired by object classes the port does not have. Of its 13 functions that had no handler, six got one in round 19 (DestroyProp, EffectFadeObject, StreamRoomIn, SetPartyCharacter, EnableDistanceFade, AddToSemiTransNearCameraList: [script-system-natives-world.md](script-system-natives-world.md)); the waypoint class starts `1-2_MissionStart` by play.

## 3. Verified behaviour

- In the original `1-2_MissionStart` is started by the update of the waypoint class (not by a trigger or an event) when the player reaches the waypoint; the natives then run in the order of the script, `DestroyProp` after the 5 s title camera and `PlayCharAnim` after the following `Wait 5`: [scripts-missions.md §2026-10-14T21:39](../../re/scripts-missions.md#ts-20261014-213921).
