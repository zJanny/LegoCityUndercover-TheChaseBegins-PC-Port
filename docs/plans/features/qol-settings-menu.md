# QoL settings menu and toggles

## 1. Scope

The settings menu of the PC port and the toggle store of all QoL features: the master toggle (Original, Custom, Improved), one toggle per feature, window mode and resolution, key bindings, and `config/qol.cfg`. Opened from the title screen and from an always shown "PC Settings" entry of the pause menu, with no extra key; tabs Game, Display, Controls and Quality of life; mouse, keyboard and gamepad. Nothing else of the `qol` plan may start before this exists. Plan: [qol.md](../qol.md).

## 7. Code and tests

Library `chase_qol` (`src/qol/`: `features.hpp` feature table, `settings.hpp`/`settings.cpp` master state, switches, window mode and resolution, strict `config/qol.cfg` reader and writer; `display_tab.hpp`/`display_tab.cpp` pure Display row model (window mode row, resolution row cycling a given list, clamp of a stored size to the largest mode); format: `master Original|Improved|Custom`, then `window_mode windowed|fullscreen` (default fullscreen) and `resolution WIDTHxHEIGHT` (minimum 400x240; absent means the desktop size and stays absent until a size is picked), then one `<feature> on|off` line per feature once an own mix exists). Game tab model: `game_tab.hpp`/`game_tab.cpp` (`GameOptions` interface, `GameTab`), test `qol-game-tab` (`tests/qol/game_tab_test.cpp`). Test `qol-settings` (`tests/qol/settings_test.cpp`) covers original mode first, master states, Custom restore, round trip and every rejection. Test `qol-display-tab` (`tests/qol/display_tab_test.cpp`) covers the rows, toggling, list cycling, the clamp to the largest mode and rejections. Further tests: one set with the feature off (unchanged behaviour) and one with it on, pinned to the design entry.

Guard: `tests/qol_separation.cmake`, CTest `qol-separation`, with `qol-separation-accepts` and one `qol-separation-rejects-<fixture>` per rule (fixtures in `tests/qol_separation_fixtures/`). Menu model: `menu_model.hpp`/`menu_model.cpp` (pure plain types: tabs, rows generic over `features.hpp`, key and pointer events, `MenuModel::handle`), test `qol-menu-model` (`tests/qol/menu_model_test.cpp`, original mode first). The Display tab of the model takes the display modes and desktop size as plain types (`MenuModel::setDisplayModes`). Controls tab model: `controls_tab.hpp`/`controls_tab.cpp` (plain `BindingEntry` list and a key-validator callback, no `input.hpp` dependency), test `qol-controls-tab` (`tests/qol/controls_tab_test.cpp`). Drawing: not written yet.
