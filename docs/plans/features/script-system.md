# Script system

## 1. Scope

The level scripts (level section +0x18), the per-update runner 0x169254, the executor 0x234204 and its words, Wait, CallScript / SpawnScript, the natives with a handler (EnableObject, EnableCollision, TriggerObject, EnableTrigger, EnableBound), the trigger pass 0x1746c0 with the bound checks, the `startup` script, the class `startup` scripts of placed objects, the camera bound and trigger start switches, the `OnSceneEnter<room>` event, the revealer links and the start state of placed objects. Class scripts and events at run time and the `ScriptCheckExtras` request source are not covered. Mission flow and enemies are not covered ([README.md](README.md) lists them as not started).

## 2. Status

IN_PROGRESS, updated 2026-10-14T15:54:28+02:00. The trigger pass checks every bound trigger type (script_triggers.*); AI and vehicle types wait for SCRIPT-42 / SCRIPT-43. `ScriptRunner` runs threads every update like the original (waits, CallScript, SpawnScript). The director camera runs: StartDCam, StartDCamTrack, WaitForDCam and EndDCam follow the oracle timing of the police entry script. The scene start (`SceneStart`) runs class `startup` scripts, the level `startup` and `OnSceneEnter<room>`, and applies the camera bound and trigger start rules; player bound triggers and `TriggerObject` start scripts. 33 natives run (`WarningDialogBox`, `PositionObject` for the player, `KillScript`, `StartDCam`, `UnlockLevel` and `CountRacesWon` among them) and 46 more as stand-ins (the 16 text natives of batch 30: tip text and dialogue lines are drawn, `FadeScreen`, five DCam natives, the batch 26 flag natives and the batch 27 progress, save and stud natives, which only record their effect); the other 166 are sorted into batches SCRIPT-29 to SCRIPT-39, SCRIPT-46 and the rests of batches 26 and 27 (SCRIPT-57 to SCRIPT-65).
