# Script system: AI movement and navigation

## 1. Scope

How an AI character moves for the script natives: the AIMove path finder and follower on the nav grids (`.bfnnav`), the simple path state of AIFollowSimplePath, the go-to-target state of AISuperJump, the speeds, and the AIMove trigger event they raise. Other AI behaviour (pursuit, stalking, fleeing, weapons) stays in [script-system-natives.md](script-system-natives.md) (SCRIPT-42).

## 2. Status

IN_PROGRESS, updated 2026-10-14T21:30:00+02:00. The path finder 0x204284, the in-grid follower and the follower across grids (transition 0x272598, phases 3 and 4 of 0x1faf04, the recovery of an unclosed start cell) are transcribed (`nav_path.*`, `nav_grid.*`, `nav_follow.*`). `chase-game` loads the nav grids of every room of the level (`nav_load.*`, with the loader fix-up of 0x1971c4) and gives them to `AiCore`, so an AIMove runs the finder and the follower: result 1 refuses the order, paths across grids are followed. Orders the follower cannot continue (result 2 of the finder, gates other than 0) still walk straight (SCRIPT-S31). The follower across grids was not compared with the original (SCRIPT-100). AISuperJump runs the set-up 0x213300 and state 11 (`ai_super_jump.*`, `ai_go_to_target.*`); the flight itself is a stand-in (SCRIPT-S103); the face state 10 is ported (`ai_face_target.*`).

## 4. Stand-ins

- SCRIPT-S31 Every AI move runs at a measured stand-in speed (player 0.11 per update walk, 0.23 run). AIMove whose finder result is 2, or whose follower cannot continue (a gate other than 0, a walled-off grid), is a straight walk ending on the target; the event argument is component byte 0 stood in by 0; pursuit, stalk, flee and the AIEnable party loop only record their state number (SCRIPT-104). needs: SCRIPT-42, SCRIPT-79, SCRIPT-92, SCRIPT-101. evidence: [ai-natives.md §2026-10-14T18:42](../../re/ai-natives.md#ts-20261014-184240).
- SCRIPT-S93 The nav section the finder works on is the first one whose lookup finds the start; the original keeps one in global 0x376bec `+4`, set once at level load from a room-name match (0x168e6c, string not resolved). Exact for levels with one section. needs: SCRIPT-94. evidence: [ai-navigation.md §2026-10-14T20:39](../../re/ai-navigation.md#ts-20261014-203953).
- SCRIPT-S94 The lookup height tolerance (entity float `+0x70`, stood in as 0.5 doubled) and the gate masks `+0x74` / `+0x78` (stood in as bit 0 only, the original adds the registered gate types of table 0x376f10) are not the original's. needs: SCRIPT-94, SCRIPT-101. evidence: [ai-navigation.md §2026-10-14T19:47](../../re/ai-navigation.md#ts-20261014-194710).
- SCRIPT-S95 The obstacle pass 0x2af1cc (run by the follower while `+0x7c` bit 0 is clear, so for a plain AIMove) and the 200-tick budget of the cell search are skipped; the search always finishes. needs: SCRIPT-95. evidence: [ai-navigation.md §2026-10-14T19:47](../../re/ai-navigation.md#ts-20261014-194710).
- SCRIPT-S100 While an AIMove follows its path the character's height is the waypoint's grid base plus the offset it had at the first step; the original character stands on the ground through its physics. needs: SCRIPT-92. evidence: [ai-navigation.md §2026-10-14T20:39](../../re/ai-navigation.md#ts-20261014-203953).
- SCRIPT-S101 The clock of 0x2355c0 that dates the temporary marks of the grids is a nav clock in `AiCore` that starts at 10 s and runs with the updates (the original uses the game time, far above 2 s at level start). evidence: [ai-navigation.md §2026-10-14T20:39](../../re/ai-navigation.md#ts-20261014-203953).
- SCRIPT-S102 All rooms of the level have their nav grids from the start; the original reads a room's file when the room object is loaded and no release was found. needs: SCRIPT-94. evidence: [ai-navigation.md §2026-10-14T20:39](../../re/ai-navigation.md#ts-20261014-203953).
- SCRIPT-S103 AISuperJump flight: the character covers `+0x308` (distance / frames) per 1/30 s toward the target and follows a parabola from its height through the apex `+0x30c` above the start to the target height; the original moves it with locomotion state 72. The follow-up lookup 0x1f8d5c after arrival is "no target" (idle). needs: SCRIPT-103. evidence: [ai-states.md §2026-10-14T21:21](../../re/ai-states.md#ts-20261014-212158).
- SCRIPT-S104 State 11 arrival uses ATTR_RunSpeed 0.23 for every character (class values not read) and bit 6 of `+0x314` as false. needs: SCRIPT-103. evidence: [ai-states.md §2026-10-14T21:21](../../re/ai-states.md#ts-20261014-212158).
