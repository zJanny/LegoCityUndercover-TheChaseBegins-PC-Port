# Script system: natives

## 1. Scope

The script natives: census and batches (SCRIPT-7, SCRIPT-26 to SCRIPT-39), the handlers that run and the stand-ins, the AI, object, progress and save natives, and the natives that only record their effect. The director camera is in [script-system-dcam.md](script-system-dcam.md), the objective and text natives in [script-system-hud-natives.md](script-system-hud-natives.md), general items, the runner and the scene start in [script-system.md](script-system.md), the trigger pass in [script-system-triggers.md](script-system-triggers.md).
