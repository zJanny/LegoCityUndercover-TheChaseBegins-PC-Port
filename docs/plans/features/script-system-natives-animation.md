# Script system: animation and attach natives

## 1. Scope

The 13 natives of batch 32 (SCRIPT-32): PlayCharAnim, PlayAnimation, LoadAnimation, UnloadAnimation, StopCharAnim, StopAnim, WaitForCurrentAnim, WaitForCurrentCharAnim, AttachObject, AttachToBone, AttachToBoneRot, AttachToWorldRoot, AttachToRoom. The animation player they drive is in [animation-characters.md](animation-characters.md); the other natives are in [script-system-natives.md](script-system-natives.md).

## 2. Status

IN_PROGRESS, updated 2026-10-19T23:24:26+02:00. For level characters and for skinned placed props (garage shutters, dog cage, dumpster, crane, lawnmowers, gardeners, the dog and the crow) the animation natives play through the original's slot player: PlayCharAnim and PlayAnimation start clips, StopCharAnim / StopAnim stop them, the two waits block until the clip is within one frame of its length. On Player1 the three character natives hand the pose to the script clip through the user-animation state 0x50 and back to locomotion (the clip's root motion moves the player; the script runner runs before the player's update, so the request is applied in the update of the native without the old state's update, and state 0x50's update starts one update later, as measured); the attach natives only record the new parent.

## 3. Verified behaviour

- `1-1_VanBreakdown` plays `postboxstuck_idle_minifig` in a loop on `1-1_AI_DonutLady`, as the original's slot (mode 1, end 42, rate 15); the van driver is stuck in the mailbox (ANIM-7).
- PlayAnimation skips an animation that is not loaded; the mode is the low byte of argument 3; `AnimationOffset` moves the start.
- AttachObject and the bone natives attach the second object to the first (the lawnmower carries the gardener).
- A placed prop that is an animation target is skinned on its own: `open` of `Prop_Garage_shutter` (60 frames, 15 fps) makes `WaitForCurrentAnim` block for 3.9 s; CTest `prop-animation-real-data`.

- PlayCharAnim on Player1 plays the clip in the player's slots; the update of the native runs no state update and enters state 0x50 at its end, the pose shows the clip from that update; 0x2a47b0 owns the movement from the next update until the slot kind is 6 on the clock the runner saw (89 updates for `dog_cage_open_minifig` at dt 0.033); locomotion resumes one update after the update that saw kind 6, the enter functions clear the fall offset; StopCharAnim ends it at once; `WaitForCurrentCharAnim` blocks as for level characters (CTest `player-script-animation`, `player-script-animation-real-data`, `game-player-script-animation`). Measured with `tools/oracle/script-anim-order-ctrace.txt`: [script-natives-animation.md §2026-10-19T23:24](../../re/script-natives-animation.md#ts-20261019-232426).
