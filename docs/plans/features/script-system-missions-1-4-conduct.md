# Script system: missions, mission 1-4, the goons' conduct (the idle decision, the sleep, the return to the spawn point)

## 1. Scope

What an AI character in the idle state does next: the decision of AI state 0 (its gate, the sleep branch, the side slots, the target search, the sight test, the sighting into AI state 2), the request of AI state 15 and state 15 itself (the wait before the return to the spawn point and its watch), and CharacterInvulnerable in the hit receiver. Split by subtopic from [script-system-missions-1-4-fight](script-system-missions-1-4-fight.md), which keeps the AI spawners, StartState and the end of the first fight. The fight itself (AI state 2) is COMBAT-9 in [combat-characters](combat-characters.md).
